Descripción de su proyecto.- Este proyecto funciona como conversor de monedas es un proyecto hecho en JAVA y puede ser ampliado para diferentes monedas de diferentes paises.
funciona basicamente para convertir monedas de diferentes paises. esta hecho con una API para la conversion del tipo de moneda
funcionalidades.- convierte las divisas en tiempo real de este tipo de monedas
                    1) Dólar a Peso argentino
                    2) Peso argentino a Dólar
                    3) Dólar a Real brasileño
                    4) Real brasileño a Dólar
                    5) Dólar a Peso colombiano
                    6) Peso colombiano a Dólar
                    
Cómo pueden usarlo los usuarios.- Pueden usarlo muy sencillo como indica el menu Principal son tres conversiones y viceversa ademas si el usuario ingresa palabras, letras, simbolos y otros
                                  regresa al menu principal para realizar la conversion y si no desea puede salir del sistema con el numero 7
